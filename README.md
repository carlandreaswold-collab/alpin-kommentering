# Alpin kommentering

Prototype på et kommentatorverktøy for alpint (tenkt brukt under radiosending): **startkort** som bytter utøver for utøver, **resultatarkiv** per renn og sesong, og **OL/VM-oversikt**.

**Åpne den her:** https://carlandreaswold-collab.github.io/alpin-kommentering/

## Hva du ser
- Startkort per utøver: kort bio, nytt, «hele karrieren» (pallplasser per sesong), statistikk, pallplasser med renn og dato, OL/VM-medaljer og en **formkurve** med alle renn (fargede sesongbånd, scroll sidelengs).
- Piltaster ◀ ▶ bytter utøver, `/` søker.
- Data: verdenscup 2009/10–nå, OL 2018/22/26 og VM 2019/21/23/25. Resultater hentet fra fis-ski.com og kvalitetskontrollert mot FIS-biografiene. Renn som ble avlyst er ikke med.

## Vi vil gjerne ha synspunkter på
- Mangler noe du ville trengt i en sending? Er noe overflødig?
- Stemmer tallene for utøvere du kjenner godt?
- Er formkurven nyttig, eller finnes det en bedre måte å vise form på?

Alt kjører i nettleseren (`index.html` + `data.js`), uten server. Personlige notater er fjernet fra denne offentlige kopien.
